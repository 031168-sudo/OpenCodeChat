# Перенос из прошлой сессии (контекст)

## Запрос пользователя

> Сделать приложение для Android, которое общается с opencode напрямую, потому
> что веб-интерфейс в Яндекс-браузере неудобен (мелкий шрифт, неудобные кнопки).
> Выбран вариант: **нативное приложение на API** (не WebView).

## Что было сделано

1. Изучён реальный API сервера opencode (`GET /doc` — OpenAPI). Авторизация —
   HTTP Basic (`opencode` / `OPENCODE_SERVER_PASSWORD`).
2. Создан проект `/home/gmpony/OpenCodeChat` (Kotlin + Compose, тот же
   инструментарий, что у других проектов).
3. Реализованы:
   - `ApiClient.kt` — `HttpURLConnection` + `org.json`, Basic auth;
   - `Prefs.kt` — адрес/логин/пароль/модель;
   - `MainActivity.kt` — экраны: Настройки → Сессии → Чат.
4. Проверено на живом сервере: создание сессии, отправка промпта, чтение
   сообщений — работает (тестовую сессию удалили).
5. Собран и опубликован APK:
   **https://gmpony.alfanomy.ru/apk/opencode-chat-debug.apk**
