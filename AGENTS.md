# AGENTS.md — проект OpenCodeChat

## Что это

Нативное Android-приложение (Kotlin + Jetpack Compose) — клиент для **сервера
opencode**. Позволяет работать с opencode с телефона через свой удобный
интерфейс, а не через веб в браузере.

- Пакет: `ru.alfanomy.opencodechat`
- Исходники: `/home/gmpony/OpenCodeChat`
- Код: `app/src/main/java/ru/alfanomy/opencodechat/`
  - `MainActivity.kt` — UI (экраны SETTINGS / SESSIONS / CHAT)
  - `ApiClient.kt` — HTTP-клиент к API opencode
  - `Prefs.kt` — настройки (адрес, логин, пароль, модель)

## Веб-интерфейс на старых браузерах

- Caddy для `gmpony.alfanomy.ru` проксирует на `127.0.0.1:4097` —
  это `~/caddy/oc-web-proxy.js` (Node). Прокси вставляет
  `/_assets/oc-polyfill.js` в HTML перед модулями приложения.
- Полифилл `~/caddy/oc-polyfill.js` закрывает `URL.canParse`, `URL.parse`,
  `Promise.withResolvers`, `Promise.try`, `Map.groupBy`, `Object.groupBy`,
  методы Set и др. — чтобы веб-UI работал в Chrome <= 116 (MacBook 2010).
- Прокси стартует по cron `@reboot`; каждую минуту cron проверяет, что порт
  4097 слушается, и поднимает процесс заново при падении.
- Отключить: вернуть в `~/caddy/Caddyfile` `reverse_proxy 127.0.0.1:4096`,
  перезагрузить Caddy и остановить `oc-web-proxy.js`.

## Сервер opencode

- Локально: `http://127.0.0.1:4096` (за Caddy на `https://gmpony.alfanomy.ru`).
- Версия: **2.0.32** (API v2, все маршруты под `/api/...`).
- **Авторизация: HTTP Basic**, пользователь `opencode`, пароль —
  `password` из `~/.config/opencode/service.json` (в `server.env` синхронизирован).
- Полный OpenAPI: `GET /openapi.json` (JSON), с Basic-авторизацией.

## Используемые эндпоинты API (v2)

- `GET /api/info` — проверка связи / версия
- `GET /api/project` — проекты (`canonical` = путь)
- `GET /api/session?limit=1000[&directory=...]` — сессии: `{data:[...]}`
- `POST /api/session` `{title, location:{directory}}` — создать сессию
- `GET /api/session/{id}/message?limit=1000&order=asc` — сообщения: `{data:[...]}`
  (типизированные: `user` / `assistant` с `content:[text|reasoning|tool]`)
- `POST /api/session/{id}/model` `{model:{id,providerID,variant?}}` — модель сессии
- `POST /api/session/{id}/agent` `{agent}` — агент сессии
- `POST /api/session/{id}/prompt` `{text, files:[{uri,name}]}` — отправить промпт
- `GET /api/event` (SSE) — события: `data:{type,data}`, например
  `session.text.delta`, `session.step.ended`, `session.execution.succeeded`
- `GET /api/model`, `GET /api/provider` — модели и провайдеры
- `GET /api/agent`, `GET /api/command` — агенты и команды
- `GET /api/session/{id}/form` + `POST .../form/{formID}/reply` — формы (вопросы)
- `GET /api/session/{id}/permission` + `POST .../permission/{id}/reply` — разрешения
- `POST /api/pty` — shell (создание проектов: mkdir + git init)
- `POST /speech/inference` (Caddy) — распознавание речи Whisper (large-v3 q5),
  защищено тем же Basic auth, что и сервер opencode.

### Распознавание речи

- Модель: `whisper.cpp` **large-v3 q5** — файл
  `/opt/whisper.cpp/models/ggml-large-v3-q5_0.bin`.
- В контейнере `whisper-server` основной процесс остаётся на `:8080` с моделью
  `small`; рядом запущен второй сервер large-v3 на `:18080` (GPU).
- Скрипт запуска: `/opt/whisper.cpp/models/whisper-large-start.sh`; cron каждую
  минуту проверяет и поднимает его при падении.
- Caddy `handle_path /speech/*` → `172.17.0.2:18080` с Basic auth
  (`opencode`); приложение ходит на `POST /speech/inference`.
- Второй Caddy-сайт `http://100.75.84.42:18080` (Basic auth) отдаёт тот же
  Whisper напрямую через Tailscale; приложение использует его при прямом
  подключении.
- Важно: на хосте сейчас рассогласование драйвера NVIDIA (`nvidia-smi` не
  работает, новые GPU-контейнеры не стартуют). Уже запущенный контейнер
  `whisper-server` работает; после перезагрузки/пересоздания контейнера может
  потребоваться починка драйвера хоста.

Модель по умолчанию: `opencode` / `deepseek-v4.1-flash`.

## Как устроено в приложении

- Сеть: `java.net.HttpURLConnection` + `org.json` (без сторонних зависимостей,
  чтобы собиралось офлайн). Basic auth в заголовке `Authorization`.
- Отправка: `POST /session/{id}/prompt_async` (асинхронно, сервер доделывает,
  даже если приложение закрыто) + стрим `GET /event` (SSE) в реальном времени.
  По завершении (событие `session.idle`) перечитывается `GET .../message`.
- Настройки хранятся в SharedPreferences (`Prefs`).

## Что уже работает

- Название приложения — **OpenCode**; иконка в стиле «матричного дождя»
  (adaptive icon: зелёные символы на чёрном + терминальный «>_»).

- Проверка связи, список сессий, создание чата, история, отправка, ответ.
- Стриминг ответа в реальном времени (SSE `GET /event`, события
  `message.part.delta` / `message.part.updated`).
- Список проектов (объединение `GET /project` + каталоги всех сессий
  `GET /api/session`) и создание нового проекта (mkdir + git init через PTY +
  `POST /project/git/init`).
- Выбор модели и агента вручную (модели из `GET /config/providers`, агенты из
  `GET /agent`); дефолт модели — `opencode` / `deepseek-v4.1-flash`.
- Список моделей — диалог с поиском, группировкой по провайдеру и по алфавиту,
  отметкой текущей и бейджем «Бесплатно»; смена — с подтверждением.
- Ответы ассистента во всю ширину без «пузырей» (сообщения пользователя — в
  пузыре справа), как в ChatGPT/Claude.
- Индикатор заполнения контекста сессии (кольцо) и меню сессии:
  переименовать / поделиться / экспортировать / архивировать / удалить.
- На экране проекта кнопка «Использование» считает суммарную стоимость и токены
  по всем сессиям каталога (включая подсессии, с пагинацией списка).
- Файлы проекта: экран из меню «+» в чате и иконка папки на экране проекта.
  Просмотр каталогов, поиск (`/api/fs/find`), предпросмотр текста и картинок
  (`/api/fs/read/*`), загрузка (`/api/experimental/fs/write`), создание папки,
  переименование и удаление файлов/папок (через PTY: `mkdir`, `mv`, `rm -rf`).
- В поле ввода `@` открывает поиск файлов проекта с навигацией по папкам;
  выбранный файл добавляется в prompt как mention (`file://...` + `mention`),
  сервер сам читает его содержимое.
- Голосовой ввод: красная кнопка 🎤 справа от текста в композере. Запись WAV
  16 кГц mono (до 120 с), красная кнопка остановки и таймер; распознавание через
  `/speech/inference` (Whisper large-v3 q5), результат вставляется в поле ввода.
- Слэш-команды: ввод `/` открывает меню команд (`/new`, `/undo`, `/compact`,
  `/fork`, `/export`, `/share` + пользовательские из `GET /command`).
- Композер в стиле веб-интерфейса opencode: `+` | пилюля модели ⌄ |
  круглая кнопка отправки ↑; микрофон — красный, внутри поля ввода справа от
  текста. Название модели в пилюле автоматически ужимается по ширине, чтобы
  влезало целиком.
- Диалог подтверждения разрешений (события `permission.asked` / `permission.v2.asked`,
  ответ `POST /session/{id}/permissions/{permissionID}`).
- Диалог вопросов opencode (события `question.asked` / `question.v2.asked`, ответ
  `POST /question/{requestID}/reply`), чтобы чат не «зависал» в ожидании выбора.
  Ожидающие вопросы/разрешения также подхватываются при открытии сессии
  (`GET /question`, `GET /permission`) — если их задали, пока приложение было закрыто.
- Выбор «уровня размышлений» модели (variant: Default/low/high/max) из шапки чата,
  передаётся в `prompt_async` как `variant`.
- При запуске приложение открывает последнюю сессию, в которой работал.
- В настройках есть выход «← Назад», если связь уже настроена.
- Настройки → «Оформление»: тема (авто/светлая/тёмная), шрифт
  (системный/Sans/Lora/Roboto Mono; Lora и Roboto Mono встроены в APK) и размер
  шрифта (80–140%). Есть строка-пример. Хранится в `Prefs.themeMode`,
  `Prefs.fontFamily`, `Prefs.fontScale`; применяется сразу.
- Настройки → «Подключение»: режим Авто/Публичный/Tailscale, публичный адрес,
  адрес по Tailscale (по умолчанию `http://100.75.84.42:4096`), необязательный
  адрес распознавания речи и строка «Сейчас: …». В режиме Авто при старте и
  возврате из фона приложение сначала проверяет Tailscale, затем кэш/публичный
  адрес и выбирает доступный; речь автоматически идёт либо на
  `/speech/inference`, либо на `http://host:18080/inference`.
- В шапке чата слева от «Default» показывается бейдж активного канала:
  «Tailscale» или «Интернет».
- Отправка файлов/изображений (FilePartInput с data-URI) и их отображение
  миниатюрами прямо в чате.
- Сообщения рендерятся блоками: текст, «Размышление» (reasoning, только во время
  ответа) и вызовы инструментов («Редактировать … +N −M», «Оболочка …») как в
  веб-интерфейсе; в готовой истории размышления не сохраняются — только ответ.
- Ошибки провайдера (`finish: "error"` + `error.message` в сообщении ассистента,
  события `session.step.failed` / `session.execution.failed`) показываются красным
  блоком с иконкой — как в вебе (например, «Insufficient account funds»).
- Для скорости и памяти грузится только последний вопрос и последние ~20
  ответов/шагов сессии (длинные вложения и старые tool-выводы не тянутся).
  Кэш не хранит вложения и ограничен 1.5 МБ.
- Пока ассистент работает, внизу чата бегут пульсирующие точки и индикатор
  прогресса, а над композером — полоса «opencode работает…».
- Стартовые запросы (проекты, модели, агенты, команды, история) выполняются
  параллельно, чтобы чат открывался сразу.
- Управление списком моделей: «Настроить модели» в диалоге выбора модели
  (поиск по названию/ID/провайдеру, чекбоксы по провайдерам, «Показать все» /
  «Скрыть все»), выбор сохраняется.
- При переключении сессии чат сразу очищается — пока грузится новая история,
  показывается пустой чат со спиннером, а не содержимое предыдущей сессии.
- Последний экран и содержимое чата переживают перезапуск процесса: экран
  сохраняется в `Prefs.lastScreen`, история — в локальный кэш `last_chat.json`,
  поэтому при возврате в приложение показывается то же, без очистки и «прыжка».
- Если сессия ещё выполняется на сервере (`GET /api/session/active`), приложение
  показывает «opencode думает…» и по завершении само подтягивает готовый ответ.
- При возврате в приложение (`onResume`) сессия перепроверяется: если она ещё
  думает — снова включается индикатор и ожидание результата; если уже
  закончила (или SSE-соединение оборвалось) — история тихо обновляется.
- При открытии сессия сразу прокручивается в конец (без animate-«простыни»).
- Если промотать историю вверх, над полем ввода появляется полупрозрачная
  круглая кнопка со стрелкой вниз — плавно прокручивает диалог в самый конец.
- Иконки Material 3 (`material-icons-extended`); тёмная тема (по системной
  настройке) + markdown в сообщениях с кликабельными ссылками.
- Текст сообщений выделяется долгим нажатием (`SelectionContainer`): ползунки
  и системное меню Android (копировать / выделить всё).
